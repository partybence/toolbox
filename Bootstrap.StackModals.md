# Bootstrap.StackModals

This helper simply provides an event listener to auto-adjust Bootstrap Modals' z-index values in order to display multiple of them on top of each-other.

This is all it does... this is event-driven... there's no constructor, no functions and definitely no return values...

Why I made this anyway? Because either I was blind or nobody seemed to be concerned that with just a simple thing like this, Modals could build a whole popup system.
